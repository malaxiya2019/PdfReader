# All PDF Reader v1.4.0

## 更新内容

- ✅ 文件扫描权限：Android 11+ 运行时权限请求
- ✅ 首页"最近文件"：真实阅读记录，按最近打开时间排序
- ✅ 页面自动刷新：从阅读器返回或权限设置返回时自动刷新
- ✅ 文件搜索功能：在"文件"标签页可搜索 PDF 文件名
- ✅ CI 构建修复：GitHub Actions 自动构建 Debug APK

## 技术栈

- Flutter SDK 3.24.5 / Dart 3.5.4
- Syncfusion PDF Viewer 26.1.35
- Material Design 3（暗黑主题默认）
- 支持 Android 5.0+（API 21+）

## 安装

下载 APK 后安装，首次打开需授予存储权限。
